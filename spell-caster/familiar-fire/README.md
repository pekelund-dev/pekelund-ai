# 🔥 Familiar Fire — Sequential Agent

> The Fire Familiar is the **sequential** member of the Spell Caster multi-agent system.  
> It demonstrates a **linear dependency chain**: Step 1 must complete before Step 2 begins.

---

## Role in the system

The Summoner routes commands that require fire-based attacks to this familiar.  
It is the simplest execution pattern: **Scout → Amplify**.

```
POST /execute  {target: "dragon"}
       │
       ▼
FireFamiliarService.execute("dragon")
       │
       ├─ Step 1: SpellSearchTool.scoutSpell("dragon")
       │             queries H2 Librarium DB
       │             returns most powerful spell for element
       │
       └─ Step 2: AmplifyTool.amplify(scoutResult)
                     multiplies effective power by 1.5×
                     wraps with Ignis Amplification Protocol message
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/agent-card` | Returns the familiar's capabilities for Summoner discovery |
| `POST` | `/execute` | Runs the Scout → Amplify pipeline |
| `GET` | `/h2-console` | H2 web console for browsing the Librarium database |

### `GET /agent-card`

```json
{
  "name": "fire-familiar",
  "displayName": "Ignis — Fire Familiar",
  "description": "Sequential fire agent that scouts the Librarium database for a spell and amplifies it. Uses a linear Scout → Amplify execution chain.",
  "endpoint": "http://localhost:8091/execute",
  "skills": [
    {
      "name": "fire_attack",
      "description": "Scout the Librarium for a fire spell and amplify it with Ignis Amplification Protocol. Input: element name or attack target."
    }
  ]
}
```

### `POST /execute`

**Request:**
```json
{ "target": "fire" }
```

**Response:**
```json
{
  "familiar": "fire",
  "pattern": "sequential",
  "result": "🔥 AMPLIFIED [x1.5]: Scout found: Inferno Blast (power=95) - A massive pillar of fire that engulfs the target in searing flames → Enhanced with Ignis Amplification Protocol. Effective power multiplied by 1.5!"
}
```

## The Librarium — H2 spell database

The Fire Familiar owns the **Librarium**: an in-memory H2 database seeded with 12 spells across three elements (fire, water, earth).

Schema:

```sql
CREATE TABLE spells (
    id      BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name    VARCHAR NOT NULL,
    element VARCHAR NOT NULL,
    description VARCHAR NOT NULL,
    power   INTEGER NOT NULL
);
```

Seed data (`data.sql`):

| Name | Element | Power |
|------|---------|-------|
| Inferno Blast | fire | 95 |
| Phoenix Flame | fire | 88 |
| Magma Wave | fire | 77 |
| Ember Strike | fire | 65 |
| Moonlit Cascade | water | 91 |
| Tidal Crush | water | 82 |
| Frost Nova | water | 73 |
| Cryo Shard | water | 70 |
| Tectonic Rupture | earth | 99 |
| Boulder Barrage | earth | 80 |
| Seismic Slam | earth | 68 |
| Stone Skin | earth | 55 |

`SpellRepository.findMostPowerfulByElement(element)` returns the single highest-power spell for the given element. If no spell matches, `AmplifyTool` returns a descriptive failure message rather than throwing.

## Tools

### `SpellSearchTool`

```java
// Finds the most powerful spell for a given element
public String scoutSpell(String element)

// Keyword search across all spell names
public String searchByKeyword(String keyword)
```

### `AmplifyTool`

```java
// Amplifies a spell result with a 1.5× fire multiplier
// Returns a graceful message if no spell was found
public String amplify(String spellResult)
```

## Configuration

`src/main/resources/application.yml`:

```yaml
spring:
  datasource:
    url: jdbc:h2:mem:librarium;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE
  jpa:
    hibernate.ddl-auto: create-drop
  h2.console.enabled: true

server:
  port: 8091
```

No external dependencies. Starts standalone with just `mvn spring-boot:run`.

---

## Running

```bash
cd familiar-fire
mvn spring-boot:run
```

Verify:

```bash
curl http://localhost:8091/agent-card
curl -X POST http://localhost:8091/execute \
     -H "Content-Type: application/json" \
     -d '{"target": "fire"}'
```
